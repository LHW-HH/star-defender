# 星际防线 · Star Defender

一个用纯前端技术（HTML + CSS + JavaScript）写的太空射击小游戏，**单文件、零依赖、零构建**，双击浏览器打开即玩。

## 🎮 玩法

驾驶飞船在星空中穿梭，击落一波又一波涌来的敌机，尽可能活得久、拿高分。

## 🕹️ 操作

| 操作 | 按键 |
|------|------|
| 移动 | `←` `→` 或 `A` `D` |
| 射击 | `空格`（按住连射） |
| 鼠标 / 触摸 | 拖动飞船，自动开火 |
| 开始 / 重来 | `Enter` 或点击按钮 |

## ✨ 特性

- 🌌 视差星空背景、粒子爆炸、屏幕震动与白闪反馈
- 👾 四种敌人：**小兵**、**蛇形**、**俯冲兵**、**精英**（带血条）
- ◆ **火力升级**：拾取掉落道具，火力 1 → 3 级（3 级为三向散射）
- ❤️ 生命值系统，受击后短暂无敌
- 📈 波次递进，难度随波数上升
- 📱 响应式画布，支持键盘、鼠标与触摸操作
- 🎨 所有画面均由 Canvas 2D 实时绘制，**不含任何图片素材**

## 🚀 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建步骤。

也可以起一个本地静态服务器：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 http://localhost:8000

## 🛠️ 技术栈

- **HTML5** — 页面结构
- **CSS3** — 布局与视觉效果
- **JavaScript (ES6+)** — 全部游戏逻辑
- **Canvas 2D API** — 逐帧绘制
- **Web Audio** — *（规划中）*
